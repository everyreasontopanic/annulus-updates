# Annulus downloads

[Download the latest Annulus release](https://github.com/everyreasontopanic/annulus-updates/releases/latest).

Release packages are publicly downloadable without a GitHub account:

- macOS: signed and notarized universal (Apple Silicon + Intel) AU/VST3 installer.
- Windows: x64 VST3 installer, plus a portable VST3 ZIP with installation instructions.
- Linux: x86-64 VST3 archive with installation instructions.

Each release includes `SHA256SUMS.txt` for package verification. Choose the package
for your operating system under the release's Assets list.
